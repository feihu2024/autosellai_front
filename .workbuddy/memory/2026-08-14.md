### 通用模式（一天一次）
```ts
const AD_WATCH_DATE_KEY = 'xxxAdWatchDate'
function checkTodayAdWatched(): boolean {
  const today = new Date().toDateString()
  return uni.getStorageSync(AD_WATCH_DATE_KEY) === today
}
function setTodayAdWatched() {
  const today = new Date().toDateString()
  uni.setStorageSync(AD_WATCH_DATE_KEY, today)
}
```
点击流程：检查当天已看过 → 直接操作；未看过 → `uni.showModal` 弹窗 → 确认 → `rewardedVideoAd.show()` → `onClose` 中 `isEnded` 为真 → 记录当天 + 执行后续操作。

### 相关 API
- `reportRewardVideo({ scene_code })` POST `/v1/miniapp/reward-video/report` 上报激励视频观看
- `getRewardVideoStatus()` GET `/v1/miniapp/reward-video/status` 获取激励视频状态（当前未使用，后续可做服务端状态同步）

## 插屏广告频次门禁（useAdManager.ts）

`composables/useAdManager.ts` 的 `shouldShowAdByScene` 方法增加插屏广告频次控制：
- 仅当 `ad_type === 'SLOT_ID_WEAPP_INTERSTITIAL'` 且 `freq_control === true` 时限流
- 用 `canShow(freqKey, max_daily, min_interval)` 判断：`max_daily` 控制单日次数，`min_interval` 控制间隔秒数
- 频次 key 为 `scene_${sceneId}_${ad_unit_id}`；通过则 `recordExposure` 记录曝光
- 其他类型（模板广告、激励视频）不限流，直接返回
- 已有用例：`pages/mall/index.vue` 场景ID 9 的插屏广告，`shouldShowAdByScene` 返回 null 时广告不弹出
